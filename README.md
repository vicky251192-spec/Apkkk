# SchoolSphere

A mobile-first school management Progressive Web App starter for Android and iPhone.

## Features
- Class-wise student profiles
- Attendance register
- Academic marks records
- Extracurricular portfolio
- Export data to JSON
- Installable PWA shell

## Run locally
Open `index.html` in a modern browser or serve this folder with any static web server.

## GitHub Pages
The included GitHub Actions workflow deploys the app to GitHub Pages when pushed to `main`. Enable Pages with **GitHub Actions** as the build source in repository Settings if required.

## Important security note
This first version stores demo data in the browser on the device. It is not suitable for real student personal data or production school use. Before entering real records, connect a secured backend with authentication, role-based authorization, encrypted transport, backups, and appropriate parental consent/privacy processes.
